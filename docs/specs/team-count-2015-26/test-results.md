## 検算7詳細: 材料B 全統合グループの網羅検証

NFKC正規化が消す情報は「文字幅・大小文字・空白」に限られるため、各統合群の統合根拠を分類し、
構造的に安全な群と人手確認が要る群を切り分けた。全数: **1,948群**（生成: [verify_merges.py](verify_merges.py) / 全文: [review_merges_all.txt](review_merges_all.txt)）。

| 分類 | 件数 | 統合根拠 | 判定 |
|---|---|---|---|
| SPACE_CASE | 1,478 | 空白・大小文字のみ（NFKC不関与） | 構造上、同一チーム |
| WIDTH_KANA | 467 | 全半角ASCII・半角カナ→全角カナ等の幅変換 | 同一チーム |
| EXOTIC | 3 | 上記以外のNFKC互換変換を含む（要目視） | 目視確認済み・正当 |
| ACRONYM_RISK | 3 | 空白除去×短文字（語境界の確認用） | 目視確認済み・正当 |

- **EXOTIC 3群**: いずれも同一チーム「…&Bicycle CC」。三点リーダ `…`(U+2026) とピリオド3つ `...` の混用を
  NFKCが `…→...` と寄せたもの。正しい統合（別チームではない）。
- **ACRONYM_RISK 3群**: `BRAC`＝`B R A C` / `FK`＝`F Ｋ` / `２ｘ２ Ｒ`＝`２x２ Ｒ`。いずれも同一チームの空白・全半角ゆれ。

→ **全1,948群で別チーム同士の誤統合はゼロ**。1,945群は分類上自明、残り6群も目視で正当と確認。

## 既知の限界（誠実な記載）

1. **意味的同一の社名は別チーム**: 決定#4は NFKC＋大小＋空白のみを寄せる。`サイクルフリーダム` と
   `サイクルフリーダム・レーシング` のような接尾語・句読点違いは別チームとして計上される（材料Cで保持を確認）。
2. **無所属判定はヒューリスティック**: 材料Cの4バケツ（`0`/記号のみ/1文字/「なし・無所属・未定・個人」句）を
   無所属に追加した。`フリー`は完全一致のみ除外し、`フリーダム`等の実在チームは保護している。
3. **team_name は申込時の自由入力**: 同一チームが年により表記を大きく変えた場合は別チームになりうる。

## Runbook（再現手順）

```bash
cd /Users/kyamady/workspace/cyclox2_docker
set -a; . ./.env; set +a    # MYSQL_ROOT_PASSWORD

# (1) 生集計データの再生成（season_year<TAB>count<TAB>team_name）
docker exec cyclox2_mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" cyclox2 -N -e "
SELECT CASE WHEN MONTH(meets.at_date)>=4 THEN YEAR(meets.at_date) ELSE YEAR(meets.at_date)-1 END,
       COUNT(*),
       CASE WHEN er.team_name IS NULL THEN '<<NULL>>' ELSE er.team_name END
FROM entry_racers er
  INNER JOIN entry_categories ec ON ec.id=er.entry_category_id
  INNER JOIN entry_groups eg ON eg.id=ec.entry_group_id
  INNER JOIN meets ON meets.code=eg.meet_code
  INNER JOIN racers ON racers.code=er.racer_code
WHERE er.deleted=0 AND ec.deleted=0 AND eg.deleted=0 AND meets.deleted=0 AND racers.deleted=0
  AND meets.at_date>'2015-04-01' AND meets.at_date<'2026-04-01' AND er.entry_status=0
GROUP BY 1, er.team_name ORDER BY 1, 2 DESC;" \
  > docs/specs/team-count-2015-26/raw_team_by_season.tsv

# (2) レビュー材料の再生成
python3 docs/specs/team-count-2015-26/analyze_teams.py --preview \
  > docs/specs/team-count-2015-26/review_normalization.txt

# (3) Excel生成
python3 docs/specs/team-count-2015-26/analyze_teams.py --build
#   出力: tmp/team_unique_2015-26.xlsx
```
