## 実行結果
## 2026-11-14 実行結果
使い捨てコンテナ `ressys_total_entries_check`（8082、worktree の Race_model.php / Race.php / race/view.php のみ `:ro` マウント）＋ローカル `cyclox2` DB（本番コピー、KNS-267-003 は未収録）。

| # | 結果 |
|---|---|
| T1 | KNS-267-003 は DB 未収録のため直接比較不可。代わりに web と同じ手順（有効 group→有効 category→有効 entry_racers）の SQL と、13大会で画面値が全一致（例: XTK-256-001=410、CXK-178-001=277、KNS-178-001=688） |
| T2 | 削除行を含む大会で除外を確認（XTK-256-001: 有効410／全4800、CXK-178-001: 277／831、CCM-178-001: 88／872 など） |
| T3 | XTK-256-001: リザルト結合版409に対し画面は410（リザルト未登録1名を含む）。YGC-256-003 でも entry_racers 件数と一致 |
| T4 | 0件の大会は到達可能な範囲に無し。モデルと同形のクエリを存在しない大会コードで実行し0を確認。`empty()` ガードと `(int)` キャストは HTTP 経由では未実行 |
| T5 | 昇格者あり（/race/3951）・なし（/race/27164）の両方で `</table>`または「昇格者なし」→総エントリー数→`#cat_tab` の順 |
| T6 | 同一大会の複数レースで同一値（各大会3カテゴリーずつ確認） |
| T7 | `php -l` 3ファイルとも No syntax errors |
| 追加 | 存在しない/不正 id は404でPHPエラーなし。/、/meet、/racer/{code} は200で総エントリー数なし。`docker logs` に warning/notice/fatal なし |

検証は `tester`（独立コンテキスト）が実施し、欠陥なし。制約: 本番の KNS-267-003（653人）との照合は本番DBでのデプロイ後確認が必要。`entry_*` テーブルは外部キーにインデックスが無く、全体結合は遅いが、大会単位のクエリ（本実装）は即応。

後片付け: `docker rm -f ressys_total_entries_check` 実施、起動した `cyclox2_mysql` は元の停止状態に戻す。
